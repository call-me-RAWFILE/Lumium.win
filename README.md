## Lumium.win

Lumium.win was an executor project featuring an Electron-based user interface and a dedicated module that was reportedly capable of achieving approximately 100% SUNC and 99% UNC compatibility.

According to the project history, the Lumium.win owners initially based their work around **Integrity by Volxphy**. At a later point, the project transitioned to **Namz Pool Party Injector**. The sources being shared here are intended to document the components and code that were used throughout the development of Lumium.win.

I was **not involved in the development or ownership of Lumium.win**. This release is being made from the perspective of someone who is sharing the sources and documenting the project's history, rather than claiming authorship or ownership of the work.

### Reason for the Release

The main reason I am making these sources public is because the Lumium.win owners previously leaked my injector. That injector was subsequently patched in the following Roblox update, making the leaked version obsolete.

Because my work was shared without my permission, I decided to make the relevant Lumium.win sources available as well. This release is primarily intended to provide transparency regarding the project's components, development history, and the sources that were used by its owners.

### Source Organization

For convenience, all provided files should be placed into a single directory. Any included `.zip` archives should be extracted into that directory, after which the original `.zip` files can be removed to avoid unnecessary duplicates.

Once everything has been extracted and organized, locate the project's `.sln` file and open it with a compatible version of Visual Studio. This should provide access to the solution and its associated projects in a structured format.

The purpose of this archive is to preserve and document the sources associated with Lumium.win and to make the project's development history easier to examine.
